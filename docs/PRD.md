# 한끗차이 PRD (MVP v0.1)

> 상태: 기획 질문 1~3 확정을 바탕으로 작성. 틸론 API 세부 정보(질문 4)는 대기 중.

## 1. 목적
AI에게 답을 대신 받는 습관 때문에 스스로 생각하고 문장을 구성하는 능력이 약해지는 문제를 해결한다.
사용자가 **직접 문장을 쓰고**, AI는 **상대 역할·판정·코칭**만 맡는다.

## 2. 대상 사용자
- AI 의존을 줄이고 사고력·표현력을 키우고 싶은 사람
- 대화 능력을 기르고 싶은 사람
- 채팅으로 소통하며 적절한 답변을 고민하는 사람

## 3. 핵심 기능과 확정 규칙

| # | 기능 | 확정 내용 |
|---|---|---|
| 1 | 한끗차이 대결 | **미션+게이지형**. 상대 캐릭터·미션·시작 게이지·목표 게이지·턴 제한(5턴). 목표 도달 시 승리, 턴 소진 또는 게이지 0이면 패배 |
| 2 | AI 맞춤형 반응 | 매 턴 AI가 캐릭터로 반응 + 게이지 변화(−20~+20) + 근거 한 문장 |
| 3 | AI 평가 | 종료 후 논리력·상황 이해력·표현력(각 0~100), 총점=평균, 강점/보완점, **한끗 더 나은 답변** 비교 |
| 4 | 시나리오 | **기본 세트(카테고리별 2개, 총 8개) + AI 맞춤 생성**. 생성 시 MY GROWTH의 가장 약한 역량을 반영 |
| 5 | MY MINI-TTINI | 이름·캐릭터·색·성격(다정/현실/유쾌)·말투(반말/존댓말) 꾸미기, 고민 상담. **답을 대신 써 주지 않고 질문으로 생각을 유도** |
| 6 | MY GROWTH | 총 대결·승률·평균·최근 5판 변화, 역량별 평균, 약점 안내, 기록 목록 |

## 4. 화면과 사용자 흐름
```
메인(/) ─ 대결 시작 → 시나리오 선택(/battle) ─┬ 기본 시나리오 클릭
                                              └ ✨ AI 맞춤 생성
        → 대결(/battle/[id]) : 답변 입력 → 게이지 ±, 근거 표시 → … → 승/패
        → 결과 : 3대 역량 점수 + 한끗 비교 → 기록 저장 → MY GROWTH(/growth)
메인 → MY MINI-TTINI(/tini) : 꾸미기 → 상담 채팅
```

## 5. AI 구조
- 브라우저 → Next.js API Route(서버) → 틸론 GPU 모델(OpenAI 호환 `/chat/completions`).
- API 키는 서버 환경변수에만 둔다(`TILON_API_KEY`). 프론트엔드에 노출하지 않는다.
- JSON 응답은 zod로 검증하고, 형식이 틀리면 1회 재요청한다. 범위를 벗어난 값은 서버에서 자른다.
- 틸론 미설정/실패 시 **데모 모드**(규칙 기반)로 대체하고 화면에 표시한다.

| API | 용도 |
|---|---|
| `GET /api/health` | AI 연결 상태(틸론/데모, 모델명) |
| `POST /api/battle/turn` | 턴 판정 |
| `POST /api/battle/evaluate` | 종료 평가 |
| `POST /api/scenario/generate` | 맞춤 시나리오 |
| `POST /api/tini/chat` | 고민 상담 |

## 6. 데이터 구조
`src/types/index.ts` 참고: `Scenario`, `BattleState`, `ChatTurn`, `TurnResult`, `Evaluation`, `BattleRecord`, `TiniProfile`.
MVP는 로그인 없이 브라우저 localStorage에 저장한다.

## 7. 테스트 기준 (TDD)
- 엔진: 게이지 범위 0~100, delta −20~+20, 목표 도달 승리, 턴 소진·0 도달 패배, 불변성
- 파싱: 코드블록 섞인 JSON 추출, 점수 범위 보정, 총점=평균
- 서비스: 틸론 설정 시 OpenAI 호환 호출·키 헤더, 형식 오류 재요청, 실패 시 데모 대체
- API: 정상 200, 잘못된 요청 400, health에 키 미노출
- 성장: 승률·평균·약점·최근 변화 계산

## 8. 남은 결정 사항
- 틸론 API 주소/모델/제한(질문 4) → 실제 연결 테스트
- 로그인/서버 DB 필요 여부 (현재 localStorage)
