# 한끗차이 PRD v2 — 인간과 AI의 게임 공동 창작

> 대주제: 내 전공 현장을 바꾸는 AI · 전공: IT콘텐츠융합과(게임 기획/개발)
> 기존 v1(대화 대결·MINI-TTINI·MY GROWTH)은 유지하며, 공동창작이 새 핵심 흐름이다.

## 1. 한 줄 소개
사람이 방향을 정하고 AI가 한끗 다른 관점을 더해, 게임 아이디어를 실제 플레이 가능한 콘텐츠로 함께 완성하는 공동 창작 서비스.

## 2. 문제와 원인
- 게임 기획 초기에 아이디어가 익숙한 틀에 갇힌다(혼자서는 관점 전환이 어렵다).
- 생성형 AI는 완성본을 대신 써 줘서 창작 주도권과 학습이 사라진다.
- 아이디어가 문서에 머물고 플레이 경험으로 이어지지 않는다.

## 3. 사용자
게임 기획·개발 전공생, 인디 창작자, 스토리텔링 취미 창작자 — 아이디어를 넓히고, 결과를 플레이로 확인하고 싶은 사람.

## 4. 핵심 가치와 역할 분담
| 사람 | AI |
|---|---|
| 아이디어·방향 제시(IDEA) | 핵심 요소 추출, 서로 다른 방향 3개 제안(TWIST) |
| 제안 선택·직접 수정(CREATE) | 선택·수정 기록을 이어받아 발전, 다음 고민 질문 |
| 플레이로 검증(PLAY) | (사용 안 함) |
원칙: AI는 완성본을 쓰지 않는다. 창작자의 수정이 제안보다 우선한다.

## 5. 차별성
- 매번 새 답을 주는 챗봇이 아니라 **선택 기록이 다음 제안을 바꾸는** 누적형 공동 창작.
- 기록에 🤖제안 / 👤창작자 기여가 구분되어 남는다.
- 결과가 **실제 게임 장면**(정원의 '함께 만든 기억')에 반영된다.

## 6. 서비스 흐름과 화면 (구현 완료)
| 단계 | 화면 행동 | 결과 |
|---|---|---|
| IDEA `/create` | 제목·장르·세계관·캐릭터·스토리 입력 또는 「《별의 끝에서》 설정으로 채우기」 → 「TWIST 받기」 | 핵심 요소 배지 |
| TWIST | 제안 카드 3장(방향·내용·한끗 다른 점) 중 하나 클릭 | 선택 표시 |
| CREATE | 「내 생각으로 고치기」 입력 → 「함께 발전시키기」 | n차 기록 + 다음 고민, 「다음 TWIST」 반복 |
| PLAY `/play` | 「④ PLAY」 → 2.5D 데모 플레이 | 정원에 마지막 공동창작 내용이 기억 꽃으로 등장 |

## 7. 《별의 끝에서》 데모 (원작 설정 유지)
- 장르: 감성 스토리 퍼즐 어드벤처 / 2.5D 탐험 / 닫힌 결말과 반전 유지
- 흐름: PROLOGUE → STAGE 1 별의 집 → STAGE 2 잊혀진 정원 → ENDING

| 구간 | 구현 내용 |
|---|---|
| PROLOGUE | 깨어남, ★"여기는 어디지? 나는 누구였을까?" |
| 별의 집 | 이동(←→)·깊이(↑↓), 별 조각 3개, 라디오 발견 → 주파수 퍼즐 → ★"기억하고 있어? 그날의 별을." → 정원 문 열림 |
| 잊혀진 정원 | 그림자(닿으면 밀려나고 어두워짐, 전투 없음), 기억 꽃, 빛의 제단 → 거울 4개 빛 경로 퍼즐 → 마지막 조각, ★"누군가를 위해 꼭 전해야 할 말이 있었던 것 같은데…" |
| ENDING | 조각 합성 → 정체 공개 → 빛으로 흩어짐 → ★"아직… 널 기억하고 있어." → 크레딧 |

**교훈 녹이기("남을 사랑하는 너 자신도 사랑해 줘")** — ☆는 새로 쓴 대사(원작자 검토 필요)
- 조각 1~3: 남의 얘기만 들어 준 나 / 좋아하는 걸 물으면 남의 것을 답한 나 / 다 나눠 주면 남는 내 빛
- 라디오: "네 빛도 조금은 남겨 둬. 남을 사랑하는 너 자신도…"(잡음으로 끊김)
- 정원: "힘들다고 말해도 괜찮았는데" / 거울 퍼즐과 연결된 "거울에 비친 나는 어떤 얼굴이었지?"
- 엔딩: 끊겼던 말이 "…사랑해 줘."로 완성(설명 대신 회수)
- 감정 연출: 조각 수에 따라 하늘 밝기·채도·별 개수 증가

## 8. 실제 기능 vs 연출
| 실제 동작(테스트됨) | 연출용 |
|---|---|
| 이동·깊이·카메라, 상호작용, 조각 수집, 라디오 퍼즐(선명도·글자 복원), 빛 경로 계산, 그림자 충돌, 스테이지/엔딩 진행, 공동창작 → PLAY 연동 | Web Audio 합성음(피아노·첼로 '느낌', 실제 녹음 아님), CSS 수채화 질감·시차 배경 |
| 공동창작 TWIST/CREATE: **체험 모드(템플릿)**로 동작, 틸론 설정 시 실제 모델 호출 | — |

## 9. AI 구조
브라우저 → `/api/create/twist`, `/api/create/develop` (Next.js 서버) → 틸론(OpenAI 호환) 또는 체험 모드.
- 맥락 유지: 요청마다 아이디어 + 전체 창작 기록(선택·수정·결과)을 프롬프트에 포함.
- 형식 보장: zod 검증, 실패 시 1회 재요청, 그래도 실패하면 체험 모드로 대체하고 화면에 표시.
- 키는 서버 환경변수(`TILON_*`)에만 둔다.

## 10. 파일 구조 (추가분)
```
src/app/create/page.tsx, src/app/play/page.tsx
src/app/api/create/{twist,develop}/route.ts
src/components/create/create-studio.tsx
src/components/play/{stars-game,puzzles,play-loader}.tsx, audio.ts
src/lib/create/{types,mock,service}.ts (+ create.test.ts)
src/lib/play/{story,light,radio}.ts (+ play.test.ts)
```
실행: `npm run dev` → http://localhost:3000/create → PLAY. 게임은 별도 실행 파일 없이 같은 Next.js 앱의 `/play` 페이지.

## 11. 테스트·완성 기준
- 단위: 빛 경로(초기 실패/정답 성공/불변성), 라디오(선명도·복원), 원작 대사 보존, 공동창작(방향 중복 회피·수정 반영·API 400)
- 브라우저(Edge): 타이틀→3조각→라디오→정원→빛 퍼즐→마지막 조각→엔딩→크레딧 자동 완주, 콘솔 오류 0
- 사람이 직접 플레이 시 예상 8~12분(대사 읽기 포함), 자동 완주 약 33초

## 12. 범위
- 완료: 위 6~8
- 시간이 남으면: 틸론 연결 후 TWIST 품질 검증, 수채화 이미지 에셋, 실제 피아노·첼로 음원
- 확장: 공동창작 결과로 퍼즐·대사 자동 생성, 나머지 챕터(그림자 평원~하늘 정원)
